Complete JSON Reference & Educational Guide

Everything you need to know about understanding, teaching, and inspecting JSON data structures privately in the classroom or production.

🎓 Classroom & Teaching Guide

Teaching data structures or web APIs? JSON (JavaScript Object Notation) is the global standard for exchanging data across the internet.

  • Hierarchical Trees: Use the collapsible nodes (▶ / ▼) to show students how nested objects contain sub-properties.
  • Arrays vs Objects: Arrays [...] are ordered lists of items, while Objects {...} are key-value dictionaries.
  • Table View: If your JSON represents tabular data (e.g. students, grades, products), click the 📊 Table tab to visualize columns and rows automatically.

🔍 JSONPath & Fast Navigation

Need to query a specific property in code (Python, JavaScript, or jq)?

  • Click to Copy JSONPath: Hover over any node in the tree and click the path badge to copy its exact JSONPath (e.g. $.students[0].name).
  • Instant Live Search: Type in the search box to filter keys and values across the entire tree in real-time. Matches are highlighted automatically.
  • Quick Shortcuts: Press Ctrl + Enter (or Cmd + Enter) in the text area to immediately inspect your payload.

🛡️ Strict Classroom Privacy (Zero Cloud)

Why paste-tools matter for educators and professionals:

  • 100% In-Memory: Computation executes solely inside your browser's V8 JavaScript engine. No data is sent over the wire.
  • Student Privacy Protection: Pasting student names, gradebooks, or confidential configs into remote servers risks data leaks and violates GDPR/FERPA.

📋 JSON Data Types at a Glance

Type Syntax Example Description
String "Alice", "2026-11-16" Text enclosed strictly in double quotes (never single quotes in valid JSON).
Number 42, 3.1415, -10 Integers or floating point values. No leading zeroes, octals, or NaN allowed.
Boolean true, false Lowercase boolean values representing binary flags.
Null null Represents an intentional empty or unassigned value.
Object {"id": 1, "name": "Alice"} An unordered collection of key/value pairs enclosed in curly braces.
Array [1, 2, "three", true] An ordered list of zero or more values enclosed in square brackets.

Frequently Asked Questions

Are my files or text uploaded to a remote server?

No. All computation occurs 100% client-side in your browser JavaScript thread. No payload data is ever transmitted across the network.

Does JSON Viewer use advertising or behavioral trackers?

Never. OTHRYS tools have zero tracking pixels, zero analytics scripts, and set zero third-party cookies.

Can I use this tool offline?

Yes! Once loaded, JSON Viewer executes without any network dependency. You can safely disconnect your internet connection and keep using it.

Is it safe for teachers to inspect student data and classroom grades?

Yes, absolutely. Because the entire JSON parser and tree renderer runs strictly inside your local browser memory, no student names, grades, or school records leave your machine. It complies fully with GDPR and student data privacy principles.

How does JSON Viewer differ from JSONFix?

JSONFix repairs malformed or broken JSON syntax (such as trailing commas, single quotes, or missing quotes around keys). JSON Viewer takes valid JSON and lets you visually explore its structure, search keys and values, collapse nodes, copy JSONPaths, and convert nested arrays to tables.
